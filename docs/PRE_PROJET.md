# Pré-projet
FasoConnect vise les échanges administratifs du Burkina Faso pour le Hackathon 226. L'adaptation d'Element/Synapse évite de développer une cryptographie et un protocole de transport supplémentaires.
Innovation prévue : instruction de service avec objet, priorité, échéance et destinataires dans un événement chiffré ; accusé chiffré lié à l'identifiant de l'instruction. Le client devra vérifier auteur, pouvoir du responsable, destinataire et unicité logique. Cela fournit un suivi opérationnel sans preuve juridique automatique. Cette extension n'est pas réalisée.
Engagement : étendre et adapter des composants libres, publier les sources et notices requises. Hébergement prévu sur une infrastructure souveraine. La livraison actuelle constitue uniquement un socle fermé.
Équipe à compléter : intégration Matrix ; identités/révocation ; interface/accessibilité ; tests et présentation.
